# 🎮 WebVault — Browser Ports & Retro Gaming Hub

WebVault is an open-source, lightweight directory for WebAssembly (WASM) and WebGL ports of classic video games and browser tech demos.

## 🚀 Features
- ⚡ **Zero Downloads:** All games run directly inside modern web browsers.
- 🔍 **Real-time Search:** Filter ports by title, category, or keywords.
- 🎨 **Modern UI:** Built with dark mode and smooth CSS glassmorphism effects.
- 🌐 **Free Hosting:** Hosted on GitHub Pages.

## 🤝 How to contribute a new Game/Port
1. Fork this repository.
2. Open `games.json`.
3. Add a new entry following this structure:
```json
{
  "id": "unique-id",
  "title": "Game Title",
  "category": "sports/action/retro/multiplayer",
  "description": "Short description of the port.",
  "url": "[https://link-to-port.com](https://link-to-port.com)",
  "thumbnail": "[https://link-to-image.jpg](https://link-to-image.jpg)"
}
